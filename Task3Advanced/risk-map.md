# Карта рисков трансформации

## Метод оценки

Вероятность и влияние оцениваются по трёхуровневой шкале:

- низкая — маловероятное событие / локальные последствия без срыва ключевых целей;
- средняя — реалистичный сценарий / заметная задержка, стоимость или ограниченная деградация бизнеса;
- высокая — ожидаемый сценарий без специальных мер / регуляторный ущерб, остановка критичных процессов либо
  срыв программы.

Приоритет определяется сочетанием вероятности и влияния: `критический`, `высокий`, `средний`, `низкий`.
Оценка показывает исходный риск до выполнения плана управления.

Критические риски рассматриваются steering committee ежемесячно, высокие — владельцами потоков не реже раза
в месяц, средние — ежеквартально. Риск закрывается только после проверки доказательства контроля, а не после
публикации регламента.
